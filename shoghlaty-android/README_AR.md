# شغلتي – مشروع تطبيق أندرويد

تطبيق عربي بتصميم داكن لتسجيل ساعات العمل والدخل والمصروفات ومتابعة هدف شهري.

## الخصائص الموجودة
- لوحة رئيسية تعرض دخل الشهر والمصروفات والصافي وساعات العمل.
- هدف شهري افتراضي 30,000 جنيه ويمكن تغييره من الشاشة الرئيسية.
- تسجيل ساعات العمل وسعر الساعة، وحساب دخل التسجيل تلقائيًا.
- اختيار تاريخ تسجيل الشغل أو المصروف.
- تسجيل المصروفات مع وصف اختياري.
- تقرير شهري يجمع ساعات ودخل كل يوم ويعرض المصروفات.
- حفظ البيانات محليًا على الهاتف باستخدام SharedPreferences؛ لا يحتاج التطبيق إلى إنشاء حساب أو اتصال بالإنترنت.

## فتح المشروع وبناء APK
1. ثبّت Android Studio على كمبيوتر.
2. فك ضغط الملف وافتح مجلد `shoghlaty-android` من Android Studio عبر **Open**.
3. اسمح لـ Android Studio بمزامنة Gradle وتنزيل مكونات Android المطلوبة.
4. وصّل هاتف أندرويد، أو افتح محاكيًا، ثم اضغط **Run** لتجربة التطبيق.
5. لإنشاء ملف تثبيت: من القائمة **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. سيظهر ملف APK داخل `app/build/outputs/apk/debug/`.

## المتطلبات التقنية
- Android Studio حديث.
- Android SDK Platform 35.
- JDK 17.

> هذه حزمة المشروع البرمجية وليست ملف APK جاهزًا للتثبيت. بيئة العمل الحالية لا تحتوي على Android SDK أو Gradle، لذلك لم أتمكن من تجميع APK هنا. افتح المشروع في Android Studio لبنائه.
